# J3 Bots 0.17.0

**Draft.** The notes for the 0.17.0 release, kept here while it is prepared. The release workflow adds the install section and the Android certificate's digest.

Each bot's pointer moves the way a hand does. It still pins T3 Code 0.1.13.

## Updating

This release speaks **protocol 11**, as 0.9.0 to 0.16.0 do, so an app and a server on any of them keep talking in either order. Update the server first anyway, then the apps.

- **The server:** from an app, in Settings → About and updates, or `j3-bots update` on its machine. Either copies the databases into a snapshot first. This release has no migration.
- **The desktop app and the Android app** update themselves as they open, or from the prompt every paired app shows. The deb and the Mac build link to this release.
- **The web client** comes with the server.

### Rolling back

`j3-bots update --rollback` to 0.16.0 puts back the databases from the snapshot, so what changed since the update is lost. The apps keep talking to it, since 0.16.0 speaks protocol 11 too.

## What's new

### Seeing your bots at work

- **A bot's pointer moves the way a hand does: it curves, leans into the move and comes to rest upright.**
  - It picks the path that suits the way it already heads, and a new point mid-move bends the move instead of starting it again. A short move takes about half a second, a long one under a second.
  - The arrow leans into a fast move, a little, and stands upright again as it lands. Its tag never turns.
  - A click plays where the pointer lands. Thinking, the pointer drifts in a small figure eight. A tag moves out of the way of the page's edge and of another bot's tag, and a second bot comes in from behind its arrow.
  - When you take the tab, the pointers move aside along a path, and wait there. With reduced motion on, a pointer is where it points at once and does not lean.
  - On your computer, a pointer at rest draws nothing, so a page no one changes sends no pictures to whoever watches it.
